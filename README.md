# pqc-assessment

A minimal Rust workspace for the pqc-assessment project.

## Features

- Cargo-based Rust project structure
- Simple binary entry point in `src/main.rs`
- Ready for extension with real cryptography or PQC tooling

## Requirements

- Rust 1.70 or newer

## Getting started

```bash
cargo build
cargo run
cargo test
```

## Project structure

```text
pqc-assessment/
├── .github/
│   └── copilot-instructions.md
├── src/
│   └── main.rs
├── .gitignore
├── Cargo.toml
├── README.md
└── target/
```
